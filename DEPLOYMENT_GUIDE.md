## ⚡ Step 1: Push Changes to `disamee/disamee`

Your special profile README lives in the repository named `disamee/disamee`.

Run the following commands in this directory:

```bash
# 1. Add the remote URL for your profile repository (if not already set)
git remote add origin https://github.com/disamee/disamee.git

# 2. Rename branch to main if needed
git branch -M main

# 3. Push to GitHub
git push -u origin main --force
```

> **Note**: If you already have cloned `disamee/disamee` in another folder, simply copy `README.md` and the `assets/` folder into it and push!
